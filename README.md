# 大二上动态规划表 · 课程 × 周计划并线

> 视觉传达大二学生的 UI / B 端方向自学规划——把课程作业、每周自学任务、作品集产出合并成一条线。
>
> **在线访问：[hnzzsp.github.io/sophomore-planner](https://hnzzsp.github.io/sophomore-planner/)**

## 这是什么

一张根据日期自动更新的学期规划表，三个视图：

| 视图 | 内容 |
|---|---|
| **学期地图** | 16 周 × 6 维度（96 格）全景；四阶段节奏；W8 / W16 验收节点 |
| **本周执行** | 自动定位当前周：本周六维度任务、每周固定节奏、第一周每日明细（28 项可勾选） |
| **课程并线** | 8 门课转化策略、「课程作业 → 周任务 → 作品集」13 条合并链、每周 43h 时间预算 |

核心思路：**课程不是负担，是免费学分 + 作品集素材库**——课内作业按 B 端标准做深，直接对接自学计划与作品集。

## 六个维度

| 维度 | 主线 |
|---|---|
| d1 专业技能 | 色彩系统 → 排版 → 图标 → 间距栅格 → 暗色 → 数据排版 → 视觉规范 v1 |
| d2 软件与工具 | Figma 概念迁移 → 组件变体 → 表格表单 → 设计系统 → Token → 组件库 |
| d3 作品集建设 | 定位 → 案例一（界面改版）全程 → 平面作品改造 → 双平台上线 |
| d4 行业接轨 | 岗位地图 → JD 分层词频 → 设计系统案例研究 → 薪资分层与城市 |
| d5 实践与就业 | 比赛地图 → 简历 → GitHub 仓库 → 小单试水 → 30 家实习线索 |
| d6 AI 工作流 | 工具地图 → Midjourney 提示词 → Figma Make → v0 → AI 面试话术 |

## 学期节奏（2026.09 – 2027.01）

| 阶段 | 周次 | 主题 |
|---|---|---|
| 地基期 | W1–W4 | 规范起步 · 课内适应 |
| 组件期 | W5–W8 | 课内大作业选题 · 并线收益最大 |

## 技术说明

- 纯静态单文件 HTML，无框架、无依赖、无后端
- 勾选进度 / 复盘笔记保存在浏览器 localStorage
- 响应式布局，手机可访问
- 部署在 GitHub Pages
