# 大二上动态规划表 · 课程 × 周计划并线

> 视觉传达大二学生的 UI / B 端方向自学规划——把课程作业、每周自学任务、作品集产出合并成一条线。
>
> **在线访问：[hnzzsp.github.io/sophomore-planner](https://hnzzsp.github.io/sophomore-planner/)**

## 这是什么

一张根据日期自动更新的学期规划表，五个视图：

| 视图 | 内容 |
|---|---|
| **学期地图** | 16 周 × 6 维度（96 格）全景；四阶段节奏；W8 / W16 验收节点 |
| **本周执行** | 自动定位当前周：本周六维度任务、每周固定节奏、第一周每日明细（28 项可勾选） |
| **课程并线** | 8 门课转化策略、「课程作业 → 周任务 → 作品集」13 条合并链、每周 43h 时间预算 |
| **课程表** | 古典风周课表：纸面双框、印章题字；8 门课按三档配色、晚间周计划时段（占位版） |
| **复盘中心** | 每周自动复盘：完成率、维度短板、下周聚焦（自动生成）、进步轨迹图、复盘三问、可下载 .md 报告 |

核心思路：**课程不是负担，是免费学分 + 作品集素材库**——课内作业按 B 端标准做深，直接对接自学计划与作品集。

## 每周复盘（复盘中心）

打开即自动汇总，不需要手动记录：

- **本周自动复盘**：完成率、已完成数、连续复盘周数；六维度进度条；自动诊断（短板预警、零进度提醒、周中进度预警、与上周对比）；「下周聚焦」由未完成维度的下周任务自动生成
- **复盘三问**：每周三问（耗时超预估的任务 / 卡住的产出 / 下周最重要的一件事），答案自动汇入报告
- **进步轨迹**：16 周完成率柱状图 + 每周明细行（较上周 ▲▼、三问是否已答）
- **复盘报告**：一键下载 / 复制 Markdown 报告（数据 + 三问 + 下周聚焦 + 轨迹）

## 进度同步（与视觉传达大二成长规划器）

本站与本地规划器是两个独立存储，通过 JSON 文件桥接（顶栏「同步」按钮）：

- **从规划器导入**：规划器 数据页 →「导出 JSON 备份」→ 在本站「同步」里选这个文件 → 学期地图显示各维度周完成标记（✓ 已完成 · ● 进行中），本周卡片显示状态徽章
- **导出到规划器**：本站把第 1 周勾选换算成六维度周状态，生成 `vd_plan_sync_*.json` → 规划器 数据页 → 同步区 →「导入同步文件」（合并模式）→ 规划器周表同步更新
- 第 1 周状态由本站勾选实时计算；W2 起打卡在规划器里做，导出到本站看全景

## 技术说明

- 纯静态单文件 HTML，无框架、无依赖、无后端
- 勾选进度 / 复盘笔记保存在浏览器 localStorage
- 响应式布局，手机可访问
- 部署在 GitHub Pages
